# RQ206 Diagram

Inventory diagram is created from the inventory report by creating an
intermediate mermaid diagram and saving it to an SVG file.

When creating a diagram:

1. Place the found artefacts on the diagram in alphabetical order.
2. For each property of type artefact, either single or an array, create a link
   to the artefact(s) referenced by the property. The link goes from the
   artefact to the artefact that has reference (UML-style association).
3. Export the diagram to an SVG file.
