Read list of files from "files" property of the envelope JSON.

Implement user's request by using the available COG tasks:

- if problem is clear, there is enough data, and solution is ready:
  use the appropriate task to modify files and the envelope
- if problem is clear, but there is not enough data:
  - use `context-add-files` to read more files into the context
  - ask user to run a COG command, powershell command or script and provide
    the result

Envelope format:

{
  "instruction": "...",
  "files": [
    {
      "path": "path/to/file",
      "type": "text",
      "content": "...",
      "complete": true,
      "update": { ... can be ignored ... }
    }
  ]
}

CLI commands:
- `cog read <path> [arguments]` reads files into the envelope.
- `cog update` refreshes envelope files using their stored update commands.
- task commands such as `context-write-file` and `context-remove-file` modify
  project files directly.
