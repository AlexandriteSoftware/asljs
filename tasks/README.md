# Tasks

Open work that is known but not scheduled. One file per task, named
`<package>-<slug>.md`.

A task file states what is wrong or missing, why it matters, and where in the
code it lives. It is written so that picking it up needs no other context, and
it is deleted when the work lands rather than marked done.

These were moved out of `TODO.md` files, one per package, which made a finished
item an edit to a file full of unrelated ones.
