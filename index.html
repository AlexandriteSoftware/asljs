asljs

Libraries, project tools, and productivity apps to enhance everyday development. By Alexandrite Software Ltd. In JavaScript (with TypeScript).

Applications:

  • app-builder - builds this site from the repository's markdown files, and holds the sources of an AI-assisted app builder demo.
  • dash - a personal performance dashboard fed by scheduled agents.

Tools:

  • cog - AI agents context manager.
  • kb - knowledge base CLI and MCP server for markdown libraries.
  • part - defines project artefacts in markdown and validates them with rules.
  • sfmt - code formatter for TypeScript.

Libraries:

  • components - reusable web components.
  • data-binding - declarative DOM bindings via data-model.
  • dali - IndexedDB data layer with typed table abstractions.
  • eventful - adds on/off/emit to any object.
  • locator - locates files by glob patterns, exclusions and filters.
  • logging - provides logging utilities.
  • machine - provides a state-machine framework for organizing control flow.
  • money - provides utilities for handling monetary values.
  • observable - makes any object emit events on property changes.
  • tmpdir - provides temporary directory utilities for testing and development.
