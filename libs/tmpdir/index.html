tmpdir

Part of Alexandrite Software Library – a set of high‑quality, performant JavaScript libraries for everyday use.

Disposable temporary directory helper for Node.js.

Features

  • Create a temporary directory with a unique name
  • Provides helpers for creating files and subdirectories
  • Automatically cleans up the temporary directory when done
  • Prevents escaping the temporary directory path

Installation

npm install asljs-tmpdir

NPM Package: asljs-tmpdir

Usage

Basic

import { TmpDir }
  from 'asljs-tmpdir';

using tmpDir =
  new TmpDir();

await tmpDir.writeText(
  'example/file.txt',
  'Hello, world!');

console.log(
  await tmpDir.readText(
    'example/file.txt'));

// the temporary directory and its contents
// will be automatically deleted at the end of
// the using block

With logging

import { PinoLoggerProvider }
  from 'asljs-logging';
import { TmpDir }
  from 'asljs-tmpdir';

await using loggerProvider =
  new PinoLoggerProvider(
    { level: 'trace' });

const logger =
  loggerProvider
    .getLogger('TmpDir');

using tmpDir =
  new TmpDir(logger);

await tmpDir.writeText(
  'example/file.txt',
  'Hello, world!');
